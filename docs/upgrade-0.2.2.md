# 升级到 0.2.2

插件现在依赖官方 `sessionProjections` 服务保存目录生命周期的最新证明。标准 profile 已包含该服务；独立组合需加载 `dsh-session-projection`，缺失依赖会使插件明确加载失败，不退回同步扫描历史。依赖随受管插件正常安装，不需要修改会话数据。

新配置默认只包含「Skill 裁剪」，筛选模式为归一化评分严格大于 50/100，合格项全部保留。分数等于 50 不入选；前 N 项、后 N 项和其它分数模式仍可配置。这不把模型返回值变成经过校准的概率。

已有显式 `rules` 数组、空数组及自定义配置不自动覆盖。需要相同设置时，在插件配置页保留所需规则，将技能筛选目标改为“评分大于 N”，N 设为 50，然后保存。打开配置页不再自动添加工作群规则；其他规则类型与动作能力仍可自行配置。

技能裁剪现在遵循官方目录的注入时机。官方技能 registry 收集所有 provider（含 Rabi）后，选择器才读取本次待注入的可用技能名称和简介并裁剪。普通新消息不单独触发重筛；官方目录改变或压缩后不再保留原目录时，才在下一次官方目录准备中重新筛选。目录仍保留在可见上下文中时可直接复用。

裁剪消息增加 `source['dsh-smart-selector:catalog']` 元数据，仅含版本和指纹；`source.entries` 继续恰好记录实际公布的项。旧会话无此元数据时，下一次官方目录注入会正常筛选并建立记录。原会话事件不改写，不需要手工迁移。包含额外内容注入的混合目录规则链仍按原路径执行。

配置变化只在官方提供了待注入目录时检查。如果上次保留了完整目录，或关闭筛选后已公布完整目录，官方可能没有新的待注入目录；此时配置在下一次官方真实触发生效，选择器不另外注入目录或模拟一次事件。
